# Подписка Premium через Telegram Stars

## Что сделано

Я добавил рабочую систему подписки через Telegram Stars в ваше приложение Cupion. Теперь пользователи могут покупать Premium подписку за звезды Telegram.

## Три плана подписки

1. **Пробная подписка** - 1 звезда ⭐ (1 день)
2. **Месячная подписка** - 50 звезд ⭐ (30 дней)
3. **Годовая подписка** - 500 звезд ⭐ (365 дней)

## Изменения в коде

### 1. `js/telegram.js`
- Добавлена функция `createInvoice()` для создания счетов через Telegram Stars
- Добавлена функция `purchaseSubscription()` для удобной покупки подписок

### 2. `js/mock.js`
- Добавлена функция `purchaseSubscription()` для обработки покупки
- Добавлена функция `getSubscriptionStatus()` для проверки статуса подписки
- Добавлена поддержка хранения истории покупок
- Добавлена автоматическая проверка срока действия Premium

### 3. `js/api.js`
- Добавлены API методы `purchaseSubscription` и `getSubscriptionStatus`

### 4. `js/app.js`
- Обновлена функция `premiumSheet()` - теперь показывает 3 плана подписки с ценами в звездах
- Обновлен обработчик кнопки "Купить" для интеграции с Telegram Stars
- План по умолчанию изменен на `'trial'` (пробная подписка)

## Как это работает

1. Пользователь открывает экран Premium (кликает на кнопку Premium)
2. Выбирает один из трех планов (пробный, месяц, год)
3. Нажимает "Купить Premium"
4. Открывается окно оплаты Telegram Stars
5. После успешной оплаты Premium активируется на выбранный период
6. Система автоматически отслеживает срок действия и деактивирует Premium когда время истекает

## Как тестировать

### В режиме разработки (без Telegram)
Приложение работает с fallback-режимом - если Telegram API недоступен, покупка все равно срабатывает для тестирования.

### В Telegram Mini App
1. Откройте приложение через Telegram бота
2. Создайте анкету (если еще нет)
3. Перейдите в профиль
4. Нажмите на любую функцию Premium (например, добавить видео)
5. Выберите план подписки
6. Нажмите "Купить Premium"
7. Оплатите звездами в Telegram

## Структура данных

### Покупка
```javascript
{
  id: 'purchase_1234567890',
  plan: 'trial', // или 'month', 'year'
  stars: 1,      // количество звезд
  createdAt: 1234567890,
  expiresAt: 1234567890
}
```

### Пользователь с Premium
```javascript
{
  premium: true,
  premiumUntil: 1234567890  // timestamp истечения
}
```

## Цены в звездах

Я установил следующие цены:
- **Пробная**: 1 звезда (примерно $0.01)
- **Месяц**: 50 звезд (примерно $0.50)
- **Год**: 500 звезд (примерно $5.00)

Вы можете изменить цены в файле `js/telegram.js` в функции `purchaseSubscription()`.
